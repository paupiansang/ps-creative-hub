## Important

The live V7 repository already contains the real downloadable binary files in `storage/assets`. Keep those files when merging this package. This package contains the complete application code and thumbnail assets, but does not recreate the original binary JSX/ZIP/SFX files.

## Deploy

1. Keep the current `storage/assets` files.
2. Replace the application files with this package.
3. Keep the existing production database if you already have users/purchases.
4. Run `npm start`.
5. Push to GitHub; Render deploys automatically.
